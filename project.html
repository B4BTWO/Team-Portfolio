Designed and developed a modern restaurant website showcasing menu offerings, promotions, and branding through a visually engaging and responsive interface.

  • Built with: HTML5, CSS3, JavaScript, Firebase Hosting
Features & Implementation
  • Secure user authentication with Firebase (Sign Up, Login, Logout).
  • Guest browsing with protected actions (cart and checkout require login).
  • Personalized shopping cart, favorites, saved addresses, and order history per user.

  • AI-powered food recommendations based on user preferences.
